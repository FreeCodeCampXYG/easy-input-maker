# 项目宪章（charter）

- **项目名**：EasyInput Maker
- **目标**：维护一份面向 EasyInput V2.0 的公开、可构建、可测试固件基线，并提供边界清楚、可复现的 AI／Vibe Coding 学习入口。
- **范围**：
  - 做：同步适合公开的公共固件能力；维护完整 `main`、明确差异的课程起点、宿主测试、ESP-IDF 5.5.5 构建入口和硬件安全文档。
  - 不做：引入产品专属 OTA、签名、部署工具、私有资料、设备身份或真实用户配置；不把构建、烧录和实板观察混作同一类证据。
- **约束**：目标板固定为 EasyInput V2.0／ESP32-S3；GPIO、BOOT、GPIO8 共享电源、分区、通信合同和设备身份未经专项确认不得改变；所有公开日志和协作记录遵守隐私边界。
- **成功标准**：完整基线和每个课程起点都有清楚的能力差异、固定版本锚点、全量宿主测试与 ESP-IDF 5.5.5 构建证据，且课程差异不导致公共底座漂移。
- **角色**：维护者确认范围与发布；贡献者和 AI Agent 按仓库合同实现、验证并提供公开证据；学员确认烧录目标并观察真实硬件结果。
