# T14 · 离线八键钢琴与 Music Config v1

## 已确认目标

- EasyInput V2.0 离线八键钢琴：KEY1—KEY8 默认 C4—C5 大调，支持移调、调式、逐键 cents/音色和节拍器。
- 音高采用 `A4=440Hz` 与十二平均律；`cents=0` 表示无微调，不使用“0Hz”概念。
- 音频使用现有 48 kHz、16-bit、I2S 与 GPIO8/音频仲裁，不新增 I2S 控制器或绕过共享电源边界。
- 首版音色采用小型波表、ADSR 与可选拨弦合成，不提交大采样/SoundFont。

## Music Config v1

- 独立于原 App 的完整键盘 JSON，使用单独 NVS 键；原 App 重同步不能删除音乐设置。
- USB Feature Report 使用未占用的 `0x16`，固定 63 字节容器，魔数 `MUS1`、版本 `1`；首版仅 USB，BLE 配置后续单独兼容版本。
- Chrome WebHID Music Studio 是独立本地设置页；它不修改 EasyInput.exe，设置时使用者应退出 EasyInput App 以避免设备 I/O 竞争。

## 交互与音频质量

- 音高/相位增量仅在配置变化或按键边沿计算；48 kHz 音频循环只做定点相位累加、波表插值、包络和混音。
- Attack/Release 设为毫秒级渐变；按键重触发保持相位连续，避免振幅突变和爆音。
- 默认三声部，后按优先；麦克风请求优先并取消音乐输出，沿用现有 `AudioIoArbiter`。
- 节拍器首版支持 2/4、3/4、4/4、6/8，BPM 20—300。

## 验收边界

- 宿主测试覆盖音准、配置拒绝、ADSR 无突变、相位连续、节拍重音、默认配置与 Music Config wire。
- 完整宿主测试、ESP-IDF 5.5.5 / esp32s3 构建、协议/硬件范围审计后才可请求烧录。
- 烧录成功和正常 HID 枚举不等于音准、手感或节拍器体验通过；实板由使用者独立观察。

## 当前实现与阻断

- 已完成可宿主验证的 `MusicSynth` 核心：默认 C4—C5、调式/移调/逐键 cents/音色、三声部后按优先、ADSR 相位连续、节拍器时序，以及离线采样调音频率估计；`MUS1` v1 固定 63 字节 wire 编解码和拒绝非法字段测试已加入。
- 未接入 USB `0x16`、NVS 或真实 I2S。默认构建启用了既有 Speaker Assets 产品链，它已独占扬声器 I2S1；若另起音乐输出驱动会与 Boot/资产播放抢占同一硬件。必须先将 Music PCM 接入既有 `SpeakerOutput` 的唯一所有权模型，并定义麦克风调音与播放之间的切换，再继续平台接线。
- 本节点当前只能报告软件核心与整体构建通过；未烧录、未运行 App、未做真机音色/节拍/调音验证。
