# firmware-v0.2.21

本版交付三功能输入与音乐边界修复、兼容性能优化和可转交的审计留痕。

- 修复鼓机跨帧偏拍、6/8 click 间隔、暂停持续音、琴键与鼓声匹配、曲目容量/事件校验及 K8 临时发声判断。
- 修复鼓机旋钮调速失败后触发原版电脑操作、非法调式接受、保存回执混用播放结果。
- 统一音乐命令入队，缓存包络参数；保留松键补偿及原有协议布局。
- 增加三功能阅读卡、共享合同、结构图、格式规范和 EIM-20260906-01 核对快照。

发布准备证据：宿主 66/66，8 组 PCM 指纹一致，五个相关源文件目标语法检查通过。标签流水线负责完整 ESP-IDF 5.5.5 构建、清单和四文件离线固件 ZIP；成功状态以 GitHub Actions 实际结果为准。

T3 误输入、实板功耗/长时内存、完整曲目恢复与内置长曲目持久化仍未完成。未执行烧录；CI 成功不代表实板功能已验证。

历史核对文档中的“未提交/未发布”描述的是冻结快照时点；本标签是后续交付记录，不覆盖旧记录。
