# 功能变更卡模板

复制到已有 `flow/tasks/`，使用唯一任务名；不要为每个功能新建一套 flow。

- 目标功能 ID / 用户看到的名字：
- 当前槽位（只是显示顺序）：
- 一句话可观察结果：
- 当前源码入口与调用者：
- 允许改动的文件：
- 必须保持不变的行为：
- 共享消费者 / 需要读的功能卡：
- 按下、松开、旋钮的输入所有权：
- 进入成功 / 进入失败保留状态：
- 退出时释放什么，谁等待排空：
- 音频、无线、灯光和存储资源需求：
- 保存失败、队列满、掉线、录音抢占时的行为：
- 旧配置 / 外部报告兼容策略：
- 新增或调整的回归测试：
- 定向测试 / 完整宿主 / 固件构建 / 实板证据（分别填写）：
- 更新文档与当前未验证项：

只有新增功能时才填写新 ID；不要因槽位排序更改持久身份。当前没有动态功能注册框架，模板不是插件实现。
